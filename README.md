# dsh dev environment

The developer's work environment. **Not the agency.** It can disappear without affecting
production, and the agency must never depend on it.

Joins the tailnet as an ephemeral node using the OAuth client from the Render `dsh-tui` group, so
restarts do not accumulate stale devices. An always-on plan, because a free web service sleeps and
a workspace you wait for defeats the point.
